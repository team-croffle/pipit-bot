### 맥락

운영자가 쓰지 않는 기능이 있어도 끌 방법이 없었습니다. 기능마다 설정을 비워 두는 식으로 우회했고, 명령은 그대로 남아
눌러 보면 이상하게 동작했습니다.

### 결정

- 일곱 기능을 따로 끕니다: 음악, GitHub 알림, 감사 로깅, 초대 추적, 입장·퇴장 메시지, 입장 역할, 리액션 롤.
  입장 쪽 셋은 같은 페이지에 있지만 하는 일이 달라 나눴습니다.
- **꺼진 기능의 슬래시 명령은 숨깁니다.** 명령 목록은 각 명령의 등록 코드로 만들고(프레임워크와 같은 builder),
  시작할 때 프레임워크의 등록 뒤와 스위치가 바뀔 때마다 봇의 명령을 그것으로 바꿉니다. 그 사이 들어온 명령은 전역
  precondition이 "꺼져 있다"고 답합니다.
- 저장은 `data/features.json`, 없으면 전부 켜짐. **GitHub은 기존 알림 설정의 전체 스위치가 원본**입니다 — 같은 기능에
  스위치가 둘이면 서로 어긋날 수 있습니다.
- 감사 로깅을 끄는 조작 자체는 기록합니다 — 기록이 왜 멈췄는지 남도록.

### 결과

- 끄면 그 기능은 어디서도 동작하지 않습니다: 명령·리스너·API·대시보드 안내가 같은 입구(`isEnabled`)를 봅니다.
- 디스코드 클라이언트가 바뀐 명령 목록을 보여 주는 데 잠시 걸릴 수 있습니다.
- 음악을 끄면 지금 세션이 끝납니다. 켜도 다시 재생하지는 않습니다.

## Context

An operator had no way to switch off a feature they did not use. Leaving its settings empty was the workaround, and its
commands stayed, behaving oddly when used.

## Decision

- Seven features switch off separately: music, GitHub notifications, the audit log, invite tracking, join and leave
  messages, join roles and reaction roles. The three on the invites page do different things, so they are separate.
- **A switched-off feature's slash commands are hidden.** The list is built from each command's own registration (the
  same builder the framework uses) and replaces the bot's commands after the framework's registration at start-up and
  on every change. A command sent in between is answered by a global precondition saying the feature is off.
- Kept in `data/features.json`, everything on when it is missing. **For GitHub the existing master switch in the
  notification settings is the source** — two switches for one feature could disagree.
- Switching the audit log off is itself recorded, so the log says why it stops.

## Consequences

- A switched-off feature does nothing anywhere: commands, listeners, the API and the dashboard notice read the same
  entry point (`isEnabled`).
- Discord clients can take a moment to show the changed command list.
- Switching music off ends the current session; switching it on does not resume playing.
