# 로드맵

<p align="center"><a href="./ROADMAP.md">English</a></p>

Pipit이 지나온 길과 앞으로 갈 방향입니다. 약속이 아니라 방향이며, 팀이 봇을 쓰면서 버전과 내용은 바뀔 수 있습니다.
배포된 버전마다 [릴리즈 노트](https://github.com/team-croffle/pipit-bot/releases)가 있고, 그 뒤의 큰 결정은
[decisions](./decisions/000_README.md)에 정리되어 있습니다.

## 배포됨

### v0.5 — 봇 하나, 대시보드 하나

- 디스코드 봇, HTTP API, 웹 대시보드가 한 프로세스로 동작
- 음악 재생은 작은 HTTP 계약으로 외부 **music worker**에 맡기고, 봇은 준비된 파일만 재생
- 대시보드 로그인은 OIDC, 설정은 코드가 아니라 JSON 파일로 보관
- 입장·퇴장 메시지, 초대 추적, 입장 시 역할 부여

### v0.6 — GitHub 리마인더와 팀 도구

- GitHub App이 PR·Issue 이벤트를 저장소마다 정한 채널로 알리고, 필요한 사람을 멘션하며, 항목마다 메시지 하나를 최신
  상태로 유지
- 알림 문구·임베드·라우팅을 대시보드에서 실시간 미리보기와 함께 편집
- 봇이 직접 게시하는 리액션 롤 패널
- `!remind`로 PR·Issue가 기다리는 사람을 다시 부르기
- GitHub 팀을 디스코드 역할에 연결, GitHub 페이지의 모든 선택 창을 같은 방식으로 통일
- 대시보드 재설계: 하나의 디자인 시스템, 라이트·다크 테마, 휴대폰에서도 사용 가능

### v0.7.0 — 대시보드에서 음악 조작

- 통화방 참여·이동·나가기, 볼륨, 대기열의 곡마다 조작, 다음에 재생 — 디스코드뿐 아니라 대시보드에서도

### v0.7.1 — 음악 관리와 디스코드 리모컨

- 음악 작업이 언제나 끝나고, 취소·다시 시도할 수 있으며, 실패 이유를 알려 줌
- 대기열 순서 바꾸기·섞기, 최근 재생과 이전 곡
- 음악 채널의 리모컨 배너 — 대기 화면과 재생 중 화면, 버튼 조작, 조작한 사람에게만 보이는 결과 안내. 채널에 친 요청은
  처리 후 정리
- 모든 명령을 슬래시 명령으로 전환
