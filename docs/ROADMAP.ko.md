# 로드맵

<p align="center"><a href="./ROADMAP.md">English</a></p>

Pipit이 지나온 길과 앞으로 갈 방향입니다. 약속이 아니라 방향이며, 팀이 봇을 쓰면서 버전과 내용은 바뀔 수 있습니다.
배포된 버전마다 [릴리즈 노트](https://github.com/team-croffle/pipit-bot/releases)가 있고, 그 뒤의 큰 결정은
[decisions](./decisions/000_README.md)에 정리되어 있습니다.

## 배포됨

### v0.5 — 봇 하나, 대시보드 하나

- 디스코드 봇, HTTP API, 웹 대시보드가 한 프로세스로 동작
- 음악 재생은 작은 HTTP 계약으로 외부 **music worker**에 맡기고, 봇은 준비된 파일만 재생
- 대시보드 로그인은 OIDC, 설정은 코드가 아니라 JSON 파일로 보관
- 입장·퇴장 메시지, 초대 추적, 입장 시 역할 부여

### v0.6 — GitHub 리마인더와 팀 도구

- GitHub App이 PR·Issue 이벤트를 저장소마다 정한 채널로 알리고, 필요한 사람을 멘션하며, 항목마다 메시지 하나를 최신
  상태로 유지
- 알림 문구·임베드·라우팅을 대시보드에서 실시간 미리보기와 함께 편집
- 봇이 직접 게시하는 리액션 롤 패널
- `!remind`로 PR·Issue가 기다리는 사람을 다시 부르기
- GitHub 팀을 디스코드 역할에 연결, GitHub 페이지의 모든 선택 창을 같은 방식으로 통일
- 대시보드 재설계: 하나의 디자인 시스템, 라이트·다크 테마, 휴대폰에서도 사용 가능

### v0.7.0 — 대시보드에서 음악 조작

- 통화방 참여·이동·나가기, 볼륨, 대기열의 곡마다 조작, 다음에 재생 — 디스코드뿐 아니라 대시보드에서도

### v0.7.1 — 음악 관리와 디스코드 리모컨

- 음악 작업이 언제나 끝나고, 취소·다시 시도할 수 있으며, 실패 이유를 알려 줌
- 대기열 순서 바꾸기·섞기, 최근 재생과 이전 곡
- 음악 채널의 리모컨 배너 — 대기 화면과 재생 중 화면, 버튼 조작, 조작한 사람에게만 보이는 결과 안내. 채널에 친 요청은
  처리 후 정리
- 모든 명령을 슬래시 명령으로 전환

### v0.7.2 — 감사 로그와 초대 추적

- 대시보드·디스코드에서 한 조작, GitHub 알림, 멤버 입장·퇴장을 기록하고 대시보드에서 보기. 음악은 누가 어떤 기능을 썼는지만
- 초대 코드별 유입 수와, 입장·퇴장의 사실만 남기는 기록 채널

### v0.7.3 — 곡 검색

- 디스코드 명령·음악 채널 리모컨·대시보드에서 곡을 검색하고, 결과 최대 5개 중에서 골라 바로 재생하거나 다음 곡으로

### v0.7.4 — 재생목록

- 서버 공용(누구나 수정)과 개인 재생목록 — 지금 곡·대기열·최근 재생·검색 결과·직접 입력에서 담고, 순서대로 또는 섞어서 재생
- 디스코드 `/playlist`와 리모컨 버튼, 대시보드 어디서나. music worker가 지원하면 링크 하나로 여러 곡 가져오기
- music worker가 지원하는 선택 기능을 알려 주면 봇이 그 버튼만 보여 줌

### v0.7.5 — 재생 옵션

- 한쪽 이어폰을 위한 모노, 대기열이 끝나도 music worker가 고른 곡으로 이어지는 자동 재생, 0–200으로 1씩 맞추는 볼륨
- 리모컨·대시보드의 재생 막대 개선, 대시보드 다듬기(아이콘, 로깅·음악 작업 페이지 나누기)

### v0.7.6 — 기능별 켜고 끄기

- 기능 단위로 켜고 끕니다. 끄면 그 기능의 디스코드 명령도 사라집니다
- 감사 로그 다듬기

### v0.7.7 — music worker 상태

- music worker가 내려가 있으면 음악 채널 배너, 명령 응답, 대시보드가 그렇다고 알리고, 되살아나면 저절로 돌아옵니다

### v0.8.0 — 데이터베이스

- 쌓이는 데이터를 PostgreSQL로 이전 — 추적 중인 GitHub 메시지, 감사 로그, 초대 통계, 재생목록, 리액션 롤 패널, 계정 연결
- 설정 파일은 그대로 둡니다 — 대시보드에 들어갈 수 없을 때도 편집기로 고칠 수 있도록
- 운영자는 데이터베이스가 하나 더 필요합니다. compose에 포함되며, 이미 쓰고 있는 PostgreSQL을 가리켜도 됩니다

## 진행 중

### v0.8.1 — 음악 결산

- 월말·연말 음악 결산 — 재생 기록을 쌓아 디스코드에 게시하고, 대시보드에서도 지난 결산과 내 결산을 봅니다. 연말에는 그 해의 재생목록이 만들어집니다. 누가 어떤 곡을 신청했는지는 어디에도 보이지 않습니다
- 손으로 친 `:tada:` 같은 이모지 숏코드도 이모지로 바뀝니다
- 결산 메시지 언어 선택(한국어·영어)

## 계획

### v0.8.2 — 대시보드 로그인

- 대시보드 로그인 화면 — 아이디·비밀번호, OIDC, Discord·GitHub 로그인 중 켜 둔 방법만 보이고, 최소 하나는 항상 켜져 있습니다

### v0.8.3 — 다국어
