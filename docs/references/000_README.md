# References

The libraries, platforms and specifications Pipit is built on — where their documentation lives, which parts of them
the project uses, and the behaviour that surprised us enough to shape the code. Read the one for the area you are about
to change before you change it.

These notes are short on purpose: the linked documentation is the source of truth, and versions here are the ones in
`package.json` at the time of writing. A note records what is specific to Pipit — how it uses the thing and what to watch
for — not a summary of the manual.
